## Deterministic defect

`Builder.BuildPathIncremental` correctly classifies a generated file when the builder has a generated-file detector. After that same file is changed through `Builder.ApplyWatchChanges` with `SubfileIncremental: true`, its `FileSummary.Generated` becomes nil. A generated file is therefore reclassified as human-authored solely because it passed through watch mode.

The exact baseline probe uses `api.pb.go` containing a valid Go package and the header `// Code generated by protoc. DO NOT EDIT.`. The initial index has `GeneratedFileCount() == 1`. After adding another function and calling `ApplyWatchChanges`, exact main fails with:

```
updated generated file count = 0, want 1
```

This is user-visible: `cmd/canopy/index.go:runIndexWatch` directly calls `ApplyWatchChanges` for `--watch --subfile-incremental`, while graph, complexity, review, context, risk, lint, report, and related commands remove generated files by default through `WithoutGenerated`. Losing the marker contaminates those analyses and their saved cache.

## Required behavior

Add the minimal production correction and a crisp regression proving all of the following:

1. An initial configured build identifies a generated Go file.
2. A changed-file watch update using `SubfileIncremental: true` still identifies that same file as generated.
3. The preserved generated metadata is meaningful (at least generator/reason, not merely a non-nil placeholder).
4. `WithoutGenerated()` still excludes the updated file.
5. Existing watch symbols/references and tree lifecycle behavior remain untouched.

Use the builder's existing detector and the already-read source bytes; do not create another detector and do not duplicate detection rules. A nil detector must continue to produce nil generated metadata without panicking.

The parse helper fills structural and file metadata but intentionally has no `Builder` receiver:

```go
func parseWatchFile(relPath, absPath string, source []byte, info os.FileInfo, parser lang.Parser, state *WatchState, subfileIncremental bool) (model.FileSummary, error) {
    if tsParser, ok, err := resolveWatchTreesitterParser(parser); err != nil {
        return model.FileSummary{}, err
    } else if ok {
        var (
            fileSummary model.FileSummary
            tree        *gotreesitter.Tree
            err         error
        )

        if subfileIncremental {
            if previous, hasPrevious := state.get(relPath); hasPrevious && previous.Tree != nil && previous.Language == parser.Language() {
                fileSummary, tree, err = tsParser.ParseIncrementalWithTree(absPath, source, previous.Source, previous.Tree)
                if err != nil {
                    return model.FileSummary{}, err
                }
            }
        }

        if tree == nil {
            fileSummary, tree, err = tsParser.ParseWithTree(absPath, source)
            if err != nil {
                return model.FileSummary{}, err
            }
        }

        fileSummary.Path = relPath
        fileSummary.Language = parser.Language()
        fileSummary.SizeBytes = info.Size()
        fileSummary.ModTimeUnixNano = info.ModTime().UnixNano()
        for i := range fileSummary.Symbols {
            fileSummary.Symbols[i].File = relPath
        }
        for i := range fileSummary.References {
            fileSummary.References[i].File = relPath
        }

        state.put(relPath, watchTreeState{
            Source:   append([]byte(nil), source...),
            Tree:     tree,
            Language: parser.Language(),
        })

        return fileSummary, nil
    }

    fileSummary, err := parser.Parse(absPath, source)
    if err != nil {
        return model.FileSummary{}, err
    }
    fileSummary.Path = relPath
    fileSummary.Language = parser.Language()
    fileSummary.SizeBytes = info.Size()
    fileSummary.ModTimeUnixNano = info.ModTime().UnixNano()
    for i := range fileSummary.Symbols {
        fileSummary.Symbols[i].File = relPath
    }
    for i := range fileSummary.References {
        fileSummary.References[i].File = relPath
    }
    if state != nil {
        state.drop(relPath)
    }
    return fileSummary, nil
}
```
